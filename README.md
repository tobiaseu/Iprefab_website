# House Finland — Powered by Iprefab

Marketplace website for Finnish prefab houses with AI-powered matchmaking, built from the Iprefab Figma prototype.

**Stack:** Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · TypeScript

## Pages (phase 1)
- `/` — Homepage: hero with house-type picker, houses carousel, builders, magazine
- `/houses` — House search with working filters (type, size, price, rooms, floors) and sorting
- Log-in modal, "Ask AI" chat assistant (mocked), responsive header and footer

## Run locally
```bash
npm install
npm run dev
```
